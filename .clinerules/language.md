# Language

- **Always respond in English.** Every reply, explanation, plan, summary, question,
  commit message, and status update must be written in English — regardless of the
  language the user writes in.
- Do not translate verbatim technical content: keep code, identifiers, file paths,
  command output, and log/error messages exactly as they appear.
- This rule is Cline-only and does not apply to other assistants in this repo; it
  supplements (never replaces) the project rules in `AGENTS.md`.
