Graph Concepts

Node Colors: Headers (.h) are cyan, Sources (.cpp) are indigo, Cycles are red.

Edges: Complete dependencies are solid, incomplete (forward declarations) are dashed.

Closure: Number of transitive dependencies.

Degree: Connection distance from selected node.

Collateral Heat Map: Color tiers (Cold/Teal, Green, Amber, Orange, Red) show inclusion weight. Noticeable fading hides unrelated nodes, and heat badges (+XX col) show specific counts. Justified dependencies (needed for your symbols) render green-outlined; heat colors continue to mark collateral burden. The inspector's Include Justification breakdown expands the top contributing header of the selected file: the symbols it is included for, the headers those symbols need, and the collateral symbols it drags along. With Preview after extraction (on justification rows and proposal cards) the map marks what the selected file would stop including (red dashed), what still arrives via other paths (amber dashed), and what the slim edge keeps (green).

Path Illumination: Illuminates the exact include path when clicking a collateral contributor.

Hotspots: The 🔥 Hotspots panel ranks the worst-offender files by a switchable metric (Collateral burden, Fan-in, Fan-out, Closure burden, Cycle participation). Clicking a row selects the file and renders its heat map live beside the open list. The 💡 Proposed extractions section below the ranking offers one-click slim-header plans that turn a hotspot into a concrete extraction.

How-To Recipes

Finding & Decoupling Header Bloat: Select a header -> inspect Collateral Breakdown -> click a heavy contributor to illuminate the include path -> refactor or forward-declare.

Triage Worst Offenders: Open 🔥 Hotspots in the toolbar -> switch the metric to rank by burden, degree, closure, or cycles -> click a row to inspect its heat map -> optionally set a directory scope chip first to rank one subtree.

Isolating Focused Subgraphs: Set Direction (Dependencies / Consumers) and step Degree (1 deg, 2 deg) or use ALL-WITH-CAP with safety node caps.

Breaking Circular Dependencies: Toggle Highlight Cycle -> inspect circular links -> use Pathfinder to see the loop.
