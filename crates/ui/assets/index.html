Graph Concepts

Node Colors: Headers (.h) are cyan, Sources (.cpp) are indigo, Cycles are red.

Edges: Complete dependencies are solid, incomplete (forward declarations) are dashed.

Closure: Number of transitive dependencies.

Degree: Connection distance from selected node.

Collateral Heat Map: Color tiers (Cold/Teal, Green, Amber, Orange, Red) show inclusion weight. Noticeable fading hides unrelated nodes, and heat badges (+XX col) show specific counts.

Path Illumination: Illuminates the exact include path when clicking a collateral contributor.

How-To Recipes

Finding & Decoupling Header Bloat: Select a header -> inspect Collateral Breakdown -> click a heavy contributor to illuminate the include path -> refactor or forward-declare.

Isolating Focused Subgraphs: Set Direction (Dependencies / Consumers) and step Degree (1 deg, 2 deg) or use ALL-WITH-CAP with safety node caps.

Breaking Circular Dependencies: Toggle Highlight Cycle -> inspect circular links -> use Pathfinder to see the loop.
