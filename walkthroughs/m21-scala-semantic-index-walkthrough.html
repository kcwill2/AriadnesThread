The seam decision (T-C, 37d7b5c, D15): placed where it can't do harm

The bug D15 fixes: registry.unit_shaper_for() is first-wins and C++ registers first - so ariadne index --lang scala on an sbt repo yielded 0 units. T-A/T-B alone changed nothing end-to-end.

The planned placement was verified impossible and wrong. Impossible: the BuildDiscoverer builder receives the language filter after construction, so compute_inputs cannot inject a filter-aware shaper. Wrong: filtering contexts at build-discovery time would poison fps.index freshness (build-stage fingerprints are derived from discovery). So the change landed at the index stage, which re-discovers through the filter-selected shaper:
