## Decisions (orchestrator rulings)

- **D10 — Import edge kind seam (neutral, C++ byte-identical).** `DependencyResolver` gains a default method `fn directive_edge_kind(&self) -> Option<IncludeKind> { None }`. C++ does not override (None → today's ownership/style logic, byte-identical). Scala overrides → `Some(IncludeKind::Import)`. `crates/graph/src/builder.rs` applies it **only** to resolver-driven `Resolved`/`Wildcard` outcomes; the on-disk-fallback path keeps `style_kind`. `IncludeKind::Import` is appended as the **last** variant in `lang-api/src/types.rs` (bincode index 3; existing serialized 0/1/2 unchanged). Graph names no language (R2) — it only matches `IncludeKind` values that live in `lang-api`.
- **D10b — `ResolveOutcome::External` gets its own builder path.** Today `External | Unresolved` share the on-disk-fallback → `style_kind` (an unresolved Scala import would land kind `Local` — wrong). New: `External` → unresolved-target edge with kind `External`, **no** on-disk fallback; `Unresolved` keeps today's path byte-identically. The C++ resolver emits only `Resolved`/`Unresolved` (verified: `lang-cpp/src/resolver.rs` docs — "External reserved … Scala's unresolved package prefix will, M20"), so this split is provably C++-inert. Acceptance plan:398 ("`import scala.collection.mutable._` becomes an External entry") rides on this.
- **D11 — CyclePolicy consumption, minimal contract.** `IncludeReport` gains `informational_cycle_count: usize` (**amended post-T-B, verified at `64b0795`: `IncludeReport` lives in `crates/graph/src/types.rs:48`, NOT `lang-api` — only `IncludeKind`/`IncludeEdge`/`SourceLocation` moved in M18.1. The field lands in `graph/src/types.rs`; T-C §2's "lang-api" touch-set line is superseded. An optional additive `import` kind counter, if wanted at all, rides the same edit with the skip-when-zero pattern**) with `#[serde(default, skip_serializing_if = "…== 0")]` → C++ `report.json` stays byte-identical, **goldens not re-pinned**. New `IncludeGraph::generate_report_with_cycle_policies(&dyn Fn(FileId) -> CyclePolicy) -> IncludeReport`; `generate_report()` delegates with `|_| CyclePolicy::Reject` (all current callers unchanged; `cycle_count` keeps counting all detected cycles — m3 untouched). Classification: a cycle is informational iff **every** member file's policy is non-`Reject`; mixed-member cycles are blocking. `Tolerate`/`TolerateWithinPackage` share the path (already conceded by `planner.rs:36-41` field docs; per-package precision is superseded by M23.5 group-condensation). Pipeline wires the policy fn from `registry.plugin_for_id(record.language).modeling().cycle_policy` (R3-legal: registry lookup, no `match LanguageId`). `planner.rs` behavior untouched — its field doc updates to record what shipped.
- **D12 — FileCatalog suffix lookup.** `FileCatalog` gains additive `pub fn by_module_path_suffix(&self, module_path: &str) -> Vec<FileId>`: normalizes `.`/`/`, returns deterministically-sorted records whose module key **ends with** the module path (so `com/example/models/User` matches `src/main/scala/com/example/models/User.scala`, and `com/example/models` matches all files under it). Needed for wildcard listing and because Scala packages don't include the `src/main/scala` prefix that `by_module_path` exact-keys on. Scala `resolve_target` policy: 1 match → `Resolved`; >1 on a wildcard directive → `Wildcard`; >1 on a named import → `Wildcard` (ambiguous, honest); 0 matches → `External` (out-of-repo package prefix — plan §3.4 Scala column). **External boundary markers**: first segment of the target ∈ `{lib, target, .ivy2, .cache}` → `External` without lookup; a matched catalog record whose rel-path has a marker component → `External`. Single source of truth: `pub const EXTERNAL_PATH_MARKERS` in lang-scala, consumed by both `plugin.rs::modeling()` (M19's lock `["lib","target",".ivy2",".cache"]` must stay green) and the resolver.
- **D13 — Fixture cycle via content-only edits.** The plan:398 "deliberate `models ↔ services` cycle" does not exist in the M19 fixture (single acyclic import). Add it **without adding/moving/removing any file** (m19 locks the exact 6-record set): `models/Order.scala` gains `import com.example.services.OrderService` + a real usage; `services/OrderService.scala` gains `import scala.collection.mutable._` + a real usage (the External lock). No file hashes feed `tests/golden` (m00 runs `basic`/`expensive` only; M19 note confirms new dirs/files outside those are safe).
- **D14 — Builder shaper seam.** Add `pub fn build_dependency_graph_with_unit_shaper(repo_path, registry, shaper: &dyn UnitShaper) -> Result<IncludeGraph>`; `build_dependency_graph` keeps its signature and delegates with `registry.unit_shaper_for()` (C++ path unchanged). The parameter is a `&dyn UnitShaper` — no language name in `graph` (R2/R3 clean). The m20 suite injects `ScalaUnitShaper`, exactly as `m19_scala_discovery_test.rs:176` injects it for build.
- **Fingerprint ruling:** lang-scala's `analysis_fingerprint()` moves from the trait default `"v1"` to `"scala-1"` in T-A (resolver is new analysis behavior; plan Goal 4 / §3.5 — fingerprint feeds the cache digest). If any existing test locks Scala's fingerprint value, keep the lock honest by updating it in the same commit with a comment; C++'s `"v1"` must not move (m18 parity).

## Orchestration protocol (non-negotiable — from the M18/M19 lessons)

- Four sequential bounded handoffs, each committing immediately on green scoped commands: **T-A** `tasks/m20-ta-handoff.md` (lang-scala resolver + catalog suffix; crate/API-local) → **T-B** `tasks/m20-tb-handoff.md` (kind seam + External path; lang/lang-api/graph) → **T-C** `tasks/m20-tc-handoff.md` (cycle-policy report + pipeline) → **T-D** `tasks/m20-td-handoff.md` (fixture + m20 suite + final gate). - Every handoff carries: exact touch-set, scoped test commands (never `--workspace` until T-D final), targeted-diff clauses, and a disk-state inventory on restart. A session whose compaction reports "empty summary" is unrecoverable — start fresh from disk state, never resume.
- Reviewer gate after each commit: APPROVED before the next handoff. Gate focuses: A = parser negatives + capability/capability-inertia check; B = **C++ byte-identity of builder paths** (m18 + m00 witnesses) + bincode index discipline; C = serde skip-when-zero + delegate equivalence; D = plan:398 verbatim + guard suites.
- Hygiene gate every commit: `python tools/hygiene_check.py` (fn < 100 lines, file < 1000) + meaningful names. R2 noun list for graph/pipeline edits: *unit, directive, dependency, external boundary* — never `scala`, `import`, `cl.exe`.
- Never script-edit UTF-8 files through `Set-Content`/`Out-File`/`>`; Read/Edit tools or byte-level UTF8-strict writes only, verified with `git diff --numstat`.
- Long cargo builds: command timeouts 600000 ms.
